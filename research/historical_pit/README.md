# Historical PIT reconstruction research

This directory documents historical reconstruction work. It is separate from `research/pit/`.

`research/pit/` contains actual contemporaneous evidence collected by production.

Historical reconstruction is evidence recovered after the fact and must never be copied into the strict live ledger merely to fill a gap.

Current Phase 4K-2 outputs are generated as workflow artifacts. Persistent source snapshots may be added later only with explicit evidence-grade metadata and checksums.
